# 静态标定数据（供日后移植新版本参考）

本目录是三合一合并时，在三个真实 EXE 上做字节级标定留下的数据与工具，**编译插件不需要它们**。

样本：

| 文件 | 版本资源 | 大小(字节) | 说明 |
|---|---|---|---|
| GTAIV1.0.7.exe | 1.0.7.0 | 15,505,792 | NGE v1.07 内核 |
| GTAIV1.0.8.exe | 1.0.8.0 | 15,718,808 | NGE v1.08 内核 |
| GTAIV1.2.0.59.exe | 1.2.0.59 | 17,425,752 | 完整版/CE（带 .rkstr/.tbm 段） |

* `addr_tables.json`：1.0.7 / 1.0.8 全部挂钩站点按“文件:行号”配对的地址表（legacy 路径的来源）。
* `ce_patterns.json`：CE 特征码引擎的全部 register_step（文件/行号/特征/期望命中数）。
* `pe_tool.py`：PE 解析 + capstone 反汇编 + 特征码搜索小工具（`Exe("107"/"108"/"ce")`）。

关键人工标定结论：

* 1.0.8 独有“跳空白再回退”3 挂钩在 1.0.7 的等价点：
  `0x46A48A→0x5B5CEA(+18)`、`0x46A4AC→0x5B5D0C(+7)`、`0x46A4EC→0x5B5D4C(+19)`。
* CE 1.2.0.59：HashString=`0x86FDD0`；grcTexturePC 字典 GetElementByKey=`0x86C570`。
* toupper：CE 形态 `66 3B CF 72 ? EB ?`（命中 0x91EE96）；
  1.0.7/1.0.8 形态 `66 81 FA E0 00 72 ? EB ?`（命中 0x7E6F6A / 0x873CBA）。
* CE 1.2.0.59 邮件函数簇寄存器分配改变，5 个特征码不命中；通用版按“mail 组整组跳过”处理，
  待补按 .59 寄存器分配的 detour 仿函数（见根目录《通用版编译与实测说明.md》第四节）。
